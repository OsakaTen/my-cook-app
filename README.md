# 冷蔵庫・レシピ提案アプリ 🍳

> **WIP / 開発中**  
> 現在実装中の機能も含まれているため、今後仕様が変更される可能性があります。

Next.js + React + TypeScript で作成した「冷蔵庫・レシピ管理アプリ」です。  
あなたの冷蔵庫の食材から最適なレシピを提案し、多種多様なコミュニティで料理の発見・共有ができることを目指しています。

## 🌟 主な機能（予定を含む）

### 📱 冷蔵庫管理・レシピ提案

- **食材在庫管理**：冷蔵庫にある食材をアプリ上で登録・編集・削除
- **賞味期限管理**：消費期限・数量を一緒に管理してフードロスを削減
- **スマートレシピ提案**：在庫食材をもとに、作れるレシピを自動提案
- **レシピ検索**：キーワードや食材からレシピを検索
- **足りない食材表示**：レシピに必要な材料のうち、不足している食材をハイライト表示

### 👥 コミュニティ機能

- **Publicグループ**：誰でも参加可能なオープンコミュニティ
- **Privateグループ**：招待制のクローズドコミュニティ
- **献立投稿**：日々の料理を写真付きで投稿・共有
- **お気に入り機能**：気に入った投稿・レシピを保存
- **いいね機能**：コミュニティメンバーの投稿にリアクション

### 🔐 ユーザー認証まわり

- ホームページは誰でも閲覧可能
- 冷蔵庫管理やコミュニティ機能の利用時にはログインが必要
- メールアドレスとパスワードによる認証（Supabase Auth を予定）

## 🚀 使い方（想定フロー）

### 1. 食材管理

1. ログイン後、「冷蔵庫」タブを開く
2. 現在の食材を名前・数量・消費期限と一緒に登録
3. 状態（新鮮 / まもなく期限切れ / 期限切れ）を確認しながら管理

### 2. レシピ提案を受ける

1. ホーム画面で「レシピ提案」を選択
2. 在庫食材から作れるレシピ一覧が表示される
3. 気になるレシピを選択して詳細（手順・材料）を確認

### 3. レシピを検索する

1. 検索タブで料理名または材料名を入力
2. 検索結果からレシピを選択
3. 不足している食材がハイライトされるので、買い物リストとしても活用可能
4. 気に入ったレシピは「お気に入り」に保存

### 4. コミュニティ機能を使う

1. 「グループ」タブから Public / Private グループを探索
2. 興味のあるコミュニティに参加 or 招待を受ける
3. 日々の料理を写真付きで投稿したり、他の人の投稿に「いいね」する
